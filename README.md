# 디지털튜터 연수 · 1일차 오후

경기도교육청 디지털튜터 연수의 강사 보조 자료입니다. 공식 교육청 서비스가 아닙니다.

- `v2/assignment.html`: 4차시 자료 대조, 기기 배정·보류 대장, 그룹·배포 계획, 15분 타이머, TXT/CSV/PDF 저장
- `v2/`: 4·5·6차시 진행표, 기기 3D 관찰, 용어·관리 사이트, 모둠 활동지
- `v2/day.html`: 업무 사례를 재구성한 90초 도입과 판단 활동

정적 HTML/JavaScript 사이트로 GitHub Pages에서 실행합니다. 서버 API와 계정 생성이 없습니다. 활동 입력은 이용자의 브라우저 localStorage에 저장되며 사이트 운영자에게 전송되지 않습니다. Padlet 공유는 이용자가 직접 게시합니다. 실제 학생·계정 정보를 입력하지 않습니다.

제공 교안의 경기희망중 가상 배정 사례를 기반으로 하며, 정상 학생 2건과 S/SIM/LOCAL 식별자는 대장 연습용 추가 예시입니다. 학교마다 권한·관리 절차가 달라질 수 있습니다. 교육청 공식 실습실은 https://goett.kr/sim/v2/ 입니다.

Three.js 라이선스: `v2/vendor/LICENSE.txt`.
