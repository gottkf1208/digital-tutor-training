# 디지털튜터 연수 · 1일차 오후

경기도교육청 디지털튜터 연수의 강사 보조 자료입니다. 공식 교육청 서비스가 아닙니다.

- `v2/assignment.html`: 4차시 시각형 실습. 10개 상황에서 자료를 보고 행동 선택 → 해설·담당자·그룹 이름 자동 정리. 단서 표시, 용어 도움말, 15분 타이머, TXT/CSV/PDF 저장
- `v2/`: 4·5·6차시 진행표, 기기 3D 관찰, 용어·관리 사이트, 모둠 활동지
- `v2/day.html`: 업무 사례를 재구성한 90초 도입과 판단 활동
- `day4/`: 4일차 후반(C3 시제품 · C4 갤러리워크 · C5 고도화 · 수료) 모션 PPT 강의안. → 다음 효과, N 강사 메모, L 목록, F 전체화면

정적 HTML/JavaScript 사이트로 GitHub Pages에서 실행합니다. 서버 API와 계정 생성이 없습니다. 선택과 진행 상태는 이용자의 브라우저 localStorage에 저장되며 사이트 운영자에게 전송되지 않습니다. Padlet 공유는 이용자가 직접 게시합니다. 실제 학생·계정 정보를 입력하지 않습니다.

제공 교안의 경기희망중 가상 배정 사례를 기반으로 하며, 정상 배정 1건과 S/SIM 식별자는 이해를 돕는 추가 예시입니다. 직접 선택한 경우와 해설을 먼저 본 경우를 구분하며, 살펴보지 않은 장면에는 완료 결과를 넣지 않습니다. 이전 입력형 실습 기록은 별도 저장 키로 유지됩니다. 학교마다 권한·관리 절차가 달라질 수 있습니다. 교안에서 사용하는 기기 지원 실습실은 https://goett.kr/sim/v2/ 입니다.
